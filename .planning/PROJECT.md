# Резюме под вакансию

## What This Is

Веб-сервис для соискателей, которые хотят собрать и редактировать базовое резюме с опытом работы и образованием, а затем адаптировать его под конкретные вакансии. Сервис анализирует текст вакансии по ключевым словам и навыкам, показывает совпадения и пробелы, а пользователь сам выбирает, какие изменения внести. Для каждой вакансии можно сохранить отдельную версию резюме и скачать её в PDF.

## Core Value

Соискатель может быстро подготовить честную и уместную версию резюме под конкретную вакансию, сохранив контроль над содержанием.

### Active

- [ ] Пользователь может создать и редактировать резюме с контактными данными, опытом работы и образованием.
- [ ] Пользователь может вставить текст вакансии и получить рекомендации по совпадающим и отсутствующим навыкам и ключевым словам.
- [ ] Пользователь может вручную настраивать резюме под вакансию и сохранять отдельные версии.
- [ ] Пользователь может скачать резюме в PDF на русском языке.
- [ ] Первая версия работает без регистрации и хранит данные в браузере пользователя.

### Out of Scope

- Аккаунты и синхронизация между устройствами — отложены до проверки базового сценария без регистрации.
- ИИ-генерация или автоматическая перепись формулировок — отложены; первая версия даёт простые рекомендации, а содержание выбирает и редактирует сам пользователь.
- Англоязычные резюме — вне объёма первой версии, которая ориентирована на русский язык.

## Context

- Проект greenfield: в рабочей папке есть только краткий README, исходного приложения пока нет.
- Основные данные резюме: опыт работы и образование; дальнейшая структура полей уточняется при проектировании.
- Подгонка под вакансию сочетает автоматический анализ совпадений с ручным выбором изменений.
- Сохранённые версии должны быть связаны с конкретными вакансиями и доступны для дальнейшего редактирования.
- Данные на первом этапе остаются в браузере; нужно учитывать сохранность и приватность пользовательских данных.

## Constraints

- **Язык**: первая версия интерфейса и формируемого резюме — русский.
- **Хранение**: без регистрации, данные хранятся локально в браузере пользователя.
- **Рекомендации**: первая версия использует сопоставление навыков и ключевых слов; ИИ отложен.
- **Экспорт**: пользователь должен получить PDF-версию резюме.
