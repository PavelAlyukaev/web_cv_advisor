## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Validated backup metadata → rendered preview | Company and vacancy labels still originate in untrusted user-controlled files. |
| Local data → user's downloaded file | Export deliberately places personal data outside browser storage and may include vacancy text. |
| User decision → import/export side effect | Dialog state controls replacement or download and must not be bypassed by stale selection state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04 | Tampering | Import preview rendering | medium | mitigate | Render company and vacancy labels through React text nodes and never interpret imported values as HTML; verify with markup-looking fixture text. |
| T-01-06 | Information Disclosure | Export dialog and browser download | high | mitigate | Show the D-08 warning on every export attempt, require explicit confirmation, and request each version's full-text inclusion separately with unchecked defaults. |
| T-01-SC | Tampering | npm package installation | high | mitigate | Preserve the mandatory package-legitimacy gate and locked dependencies from Plan 01. |
</threat_model>
