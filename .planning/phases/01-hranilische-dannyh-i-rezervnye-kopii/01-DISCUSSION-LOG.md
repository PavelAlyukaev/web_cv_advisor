## Импорт при наличии данных

| Вариант | Описание | Выбран |
|---|---|---|
| Показать содержимое и после подтверждения заменить текущие данные | Импорт работает как восстановление; пользователь видит состав файла до замены. | ✓ |
| Объединить данные и разбирать совпадения | Добавить записи из файла к существующим данным и обрабатывать дубли. | |
| Заменить данные сразу без подтверждения | Немедленно заменить текущее содержимое браузера. | |

**Предпросмотр:** показать число резюме и версий, названия компаний и вакансий. Выбор полных текстов или только предупреждения отклонён.

**Перед заменой:** предложить скачать копию текущих данных — выбран вариант «Да».

**Ошибки файла:** повреждённый или неподдерживаемый JSON отклоняется с объяснением; текущие данные остаются без изменений. Частичный импорт не выполнять.

## Состав резервной копии

| Вариант | Описание | Выбран |
|---|---|---|
| Сохранять полный текст вакансии вместе с версией | Полностью восстанавливает контекст адаптации. | |
| Сохранять только название и компанию | Не включает исходный текст вакансии. | |
| Спрашивать при каждом экспорте | Пользователь выбирает, включать ли текст вакансии в конкретный файл. | ✓ |

**Даты версий:** сохранять дату создания и последнего изменения.

**Имя файла:** автоматически формировать `resume-backup-YYYY-MM-DD.json`.

**Предупреждение о конфиденциальности:** показывать перед каждым экспортом, что JSON содержит личные данные и не защищён паролем.
