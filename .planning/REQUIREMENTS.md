# Требования: Резюме под вакансию

**Определены:** 2026-11-04  
**Ключевая ценность:** Соискатель может быстро подготовить честную и уместную версию резюме под конкретную вакансию, сохранив контроль над содержанием.

## Требования v1

### Основное резюме

- [ ] **RESUME-01**: Пользователь может создать и редактировать основное резюме с контактами, кратким описанием, навыками, опытом работы и образованием.
- [ ] **RESUME-02**: Пользователь может добавлять, редактировать и удалять несколько записей об опыте работы.
- [ ] **RESUME-03**: Пользователь может добавлять, редактировать и удалять несколько записей об образовании.
- [ ] **RESUME-04**: Пользователь может вернуться к сохранённому резюме после повторного открытия сайта в том же браузере.

### Вакансии и рекомендации

- [ ] **VACANCY-01**: Пользователь может внести текст вакансии и указать её название и компанию.
- [ ] **MATCH-01**: Пользователь может получить сопоставление ключевых слов вакансии с содержимым резюме.
- [ ] **MATCH-02**: Пользователь видит найденные и ненайденные ключевые слова, а также места найденных совпадений в резюме; автоматический подбор синонимов и словоформ не входит в v1.
- [ ] **MATCH-03**: Пользователь сам выбирает и вручную редактирует содержание резюме под вакансию; рекомендации не меняют его автоматически.

### Версии и PDF

- [ ] **VERSION-01**: Пользователь может создать отдельную версию резюме, связанную с вакансией; последующие изменения основного резюме не меняют уже созданную версию.
- [ ] **VERSION-02**: Пользователь может открыть, переименовать, редактировать и удалить сохранённую версию резюме.
- [ ] **PDF-01**: Пользователь может просмотреть выбранную версию и скачать её в PDF на русском языке.

### Локальные данные

- [x] **DATA-01**: Пользователь может экспортировать основное резюме и сохранённые версии в файл резервной копии JSON.
- [x] **DATA-02**: Пользователь может импортировать ранее созданную JSON-копию.

## Требования v2

Возможные расширения, отложенные до проверки основного сценария.

### Расширения продукта

- **FUTURE-01**: Пользователь может создать аккаунт и синхронизировать резюме между устройствами.
- **FUTURE-02**: Пользователь может получить ИИ-предложения по формулировкам, которые он проверяет и подтверждает вручную.
- **FUTURE-03**: Пользователь может находить совпадения с учётом синонимов и словоформ русского языка.
- **FUTURE-04**: Пользователь может создавать англоязычные резюме.
- **FUTURE-05**: Пользователь может выбирать дополнительные шаблоны оформления резюме.

## Вне объёма

| Функция | Причина исключения |
|---------|--------------------|
| Поиск вакансий и отправка откликов | Первая версия проверяет создание и адаптацию резюме, а не весь процесс трудоустройства. |
| Оценка вероятности прохождения ATS или найма | Сопоставление ключевых слов не позволяет достоверно предсказать решение работодателя. |
| Автоматическое добавление недостающих навыков или изменение фактов | Кандидат должен подтверждать достоверность опыта и формулировок. |
| Передача текста резюме сторонним ИИ-сервисам | Первая версия работает локально и не требует такой передачи данных. |
